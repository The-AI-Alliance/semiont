# @semiont/cli — deprecated

This package no longer provides any commands.

Install the Semiont launcher instead — a single static binary, no npm or Node.js:

```bash
brew install the-ai-alliance/semiont/semiont
```

See [apps/launcher](../launcher/README.md) for what it does. For programmatic access, use
[`@semiont/sdk`](../../packages/sdk/README.md).
